# Video Studio 方案设计

## 目标

桌面端视频格式转换与裁剪工具。能力集中在主进程 FFmpeg；渲染进程只做选文件、填参数和看进度。

## 运行时

```text
Video Studio UI
  → window.media (preload)
  → MediaIpc
  → src/main/media.ts
  → ffmpeg-static / ffprobe-static
```

| 能力 | 实现 |
| --- | --- |
| 选文件 | `dialog.showOpenDialog` |
| 探测 | `ffprobe -print_format json` |
| 转换 | `ffmpeg` + 按格式选编码（H.264/AAC 或 VP9/Opus） |
| 裁剪 | `crop=w:h:x:y`，可选 `-ss` / `-to` |
| 进度 | 解析 stderr 的 `time=` |

输出默认写到系统临时目录，不自动落盘到用户目录。界面提供结果预览；用户通过「导出到本地」选择最终路径。关闭应用时清理临时文件。

## 打包

- Vite 将 `ffmpeg-static`、`ffprobe-static` 标为 external。
- `packageAfterCopy` 把这两个包拷进安装目录。
- `asar.unpack` 解出二进制，运行时把路径中的 `app.asar` 换成 `app.asar.unpacked`。

## 边界

- 不包含智能体、会话、模型或工作区工具链。
- 超大文件与极端编码依赖本机资源与 FFmpeg 能力。
- 浏览器单独打开 Vite 页面时没有 preload，无法选文件或转码。
